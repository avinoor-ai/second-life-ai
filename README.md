# ♻️ Second Life AI

A beginner-friendly Streamlit prototype that uses AI/ML-style text matching to turn old or unused materials into practical reuse ideas.

## Features
- Enter what you have and what you want to make.
- AI recommendation engine suggests projects.
- Reference pictures are included locally.
- Shows materials, missing materials, advantages, difficulty and time.
- Built-in chatbot adapts suggestions when a material is missing.
- AI ethics section explains privacy and uncertainty.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Suggested demo
Try:
- What you have: `cardboard box`
- Want: `something useful for my desk`

Then select a project and ask the chatbot:
`I don't have glue`

## Important
This is a school-project prototype. It does not collect personal information. Always check that materials and tools are safe before making anything.
